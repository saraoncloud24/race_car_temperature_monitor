# race_car_temperature_monitor
This project simulates temperature sensor readings from a race car and identifies when temperatures exceed a predefined threshold. I built it to develop my software skills while also exploring how sensor data and software logic can be used in vehicle monitoring systems.
Technologies: Python, Matplotlib

What I learned: I learned how sensor readings can be processed using conditional logic and plotted to identify unsafe operating conditions.

Next step: Connecting a physical temperature sensor to a microcontroller in order to process sensor data
